# To-Do List App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript. This project helps users add, complete, and delete daily tasks easily.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Responsive user interface
* Simple and clean design

## Technologies Used

* HTML5
* CSS3
* JavaScript

1. Download or clone the repository.
2. Open the project folder.
